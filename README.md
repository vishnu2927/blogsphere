# 📝 BlogSphere

A modern Full Stack Blog Application built using the MERN Stack. Users can create an account, publish blogs, edit posts, comment on articles, and explore the latest technology content through a clean and responsive interface.

---

## 🚀 Features

- 🔐 User Authentication (JWT)
- ✍️ Create, Update & Delete Blog Posts
- 💬 Comment System
- 🔍 Search Blogs
- 👤 User Profile
- 📱 Fully Responsive Design
- 🌐 REST API Integration
- ☁️ MongoDB Atlas Database

---

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- Redux Toolkit
- Tailwind CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- Cookie Parser

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/blogsphere.git
```

### Install Dependencies

```bash
npm install
cd api
npm install
cd ../client
npm install
```

### Environment Variables

Create an **api/.env** file.

```env
MONGO=YOUR_MONGODB_CONNECTION_STRING

JWT_SECRET=YOUR_SECRET_KEY
```

### Run Backend

```bash
npm run dev
```

### Run Frontend

```bash
cd client
npm run dev
```
